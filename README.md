# EPR Spectrum Fitting

MATLAB script for fitting an EPR spectrum using EasySpin.

## Requirements
- MATLAB
- EasySpin, added to the MATLAB path

## Usage
Run `fit_FD_Ox_conc.m` and select your EPR data file.
